# F078.7 — search(): skip a provider after a dead key or empty credit

## Why
field measured on 14 Oct 2026: Brave's prepaid credit was empty from 03:43 to 16:17 (Danish time). The `fresh-or-country` route is `brave → cloudflare:linkup`, so each of ~2,000 `search()` calls first got a Brave 402 "Prepaid credit balance is insufficient" and only then reached Linkup. Every call still answered (the fallback worked), but each 402 was recorded as a failure: 2,029 errors in upmetrics and an alarm to the owner every hour. The answer was right; the noise and the extra latency were not.

## Scope
- In `src/search/index.ts`: a process-local cooldown. When a provider fails with HTTP 401, 402 or 403 (a key or billing state that will not fix itself in seconds), it is skipped for 10 minutes for that key.
- Skipped means: no request, no cost-sink failure row. The next provider in the chain answers.
- After 10 minutes one call tries the provider again (a probe). If it still fails, another 10 minutes. Worst case is ~6 failures/hour instead of one per call.
- The cooldown is per key: house key vs. each BYOK tenant (`labels.tenantId`). One tenant's empty credit must not reroute another tenant or the house.
- The LAST provider in a chain is never skipped. An explicit `provider:'brave'` call, or a chain whose every other entry is cooling, still tries and still throws a real error — never an empty "no provider".

## Non-goals
- No change to 429/5xx/timeout handling: those are transient and already fall through.
- No configurable duration, no shared/cross-process store. One process, fixed 10 minutes. Add knobs only if a consumer measures a need.
- No auto-topup or credit monitoring of Brave.

## Architecture
A module-level `Map<string, number>` (key → cooldown-until ms), keyed `[provider, byok ? tenant : "_house"]`. Time comes from `opts.now` so tests can move the clock. Status read via the existing `classifyFailure` (numeric `status` on adapter errors; Brave already sets it).

## Reuse
No Discovery package does provider cooldown inside a search router; this is internal routing state of `@broberg/ai-sdk` itself (the fleet's search door). Reuses `classifyFailure` from `src/cost/failure.ts`.

## Rollout
Patch release (0.62.x). Tell field (reporter) and components (Discovery note: search now skips a provider for 10 min after 401/402/403, measured fix for 14/10).
