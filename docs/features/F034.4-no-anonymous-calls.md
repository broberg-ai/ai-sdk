# F034.4 — No anonymous AI calls

## Why
Owner's order, 15 Oct 2026 (relayed by buddy, #3336): «Ingen må være anonyme». Measured in Upmetrics prod by upmetrics (#3338), last 30 days, `agent_name='unknown'`:

| project | $ | calls | sdk |
|---|---|---|---|
| field | 18.75 | 5,786 | 0.62.0 |
| mailworker | 2.36 | 141 | 0.49.0 |
| sales | 0.05 | 16 | 0.61.1 |
| helpdesk | 0.01 | 212 | 0.47.x |
| buddy | 0.01 | 889 | 0.38/0.47 |
| scout | 0 | 11 | 0.54/0.62 |
| fd-sundhed | 0 | 25 | 0.29–0.61 |
| ai-sdk | 0 | 1 | 0.50 |

On 14 Oct, 87 % of the fleet's AI spend landed as `unknown`. Cause in the SDK: `defaultCostSink()` names the sender `UPMETRICS_AGENT_NAME ?? npm_package_name ?? "unknown"`. `npm_package_name` exists only when a process is launched through `npm/bun run`, so the same app is named in dev and anonymous in prod.

## Scope
- `AiConfig.agentName?: string`. `createAI()` throws at construction when the default sink is in play (`costSink` omitted) and neither `config.agentName` nor `UPMETRICS_AGENT_NAME` is set (non-empty after trim).
- The check does NOT depend on `UPMETRICS_API_KEY`: CI usually has no key, and a check that only fires where the key exists would fire first in prod, at boot. It must fail where tests run.
- `npm_package_name` and `"unknown"` are removed as fallbacks.
- `upmetricsSink()` throws at construction on an empty/whitespace `agentName`.
- Not required: `costSink: null` (deliberate opt-out, F034.3) and an explicit `costSink` (the name lives in that sink's own config).

## Non-goals
- Upmetrics ingest stays permissive (their call, #3338: rejecting would lose the spend).
- No automatic name derivation (package.json read, hostname, git remote): every one of those is environment-dependent, which is the exact bug.

## Breaking
Yes. Every `createAI()` without a name throws. Ships as **0.63.0**: under 1.0 a caret takes patches only, so nobody receives it unasked; a repo that bumps sees it in its tests. Fix per consumer: set `UPMETRICS_AGENT_NAME=<repo>` (prod secret + test env), or `createAI({ agentName: "<repo>" })`.

## Reuse
No Discovery package owns agent identity for AI cost rows; the sink and its config are this package's own. Upmetrics is the consumer of the field.
