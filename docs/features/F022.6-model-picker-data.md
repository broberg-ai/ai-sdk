# F022.6 — Model picker data: current priced chat models, kind, per-provider default

## Motivation

Scout builds a model picker in Admin › AI key (owner order 11/10 2026: Mistral, Anthropic, OpenAI — pick a model per provider, with a default). It must read our registry (`listModels`), not a local list. Measured by scout on 0.61.1 and re-measured by ai-sdk on 2026-10-11:

- `listModels({provider:'openai'})` returns only `text-embedding-3-small` — no chat model at all.
- `listModels({provider:'anthropic'})` stops at claude-opus-4-8 / claude-fable-5. Live `GET /v1/models` (2026-10-11) lists claude-haiku-5-5 (2026-10-07), claude-sonnet-5-5, claude-opus-5-5, claude-fable-5-1, claude-opus-5, claude-sonnet-5 … none in the registry.
- No row says what it is (chat vs embedding) or which one is the provider's default.

## Scope

1. `ModelStatus` gains `kind: 'chat' | 'embedding' | 'judge'` and optional `default?: true`, `floating?: true`.
2. Registry rows for the live Claude 5 family and current OpenAI chat models. Old rows kept (a removed row would fail existing `requireKnown` gates).
3. Prices for every new chat row in `src/cost/pricing.ts`, from the official pages (Anthropic rows already priced by F075; OpenAI read from developers.openai.com/api/docs/pricing on 2026-10-11, incl. the >272K long-context rates).
4. `stripDatedSuffix` also strips OpenAI's `-YYYY-MM-DD`, so a dated OpenAI id prices like its base (the same class of bug F012 fixed for Anthropic).
5. Defaults (one per provider): mistral = the `smart` tier's model; anthropic = claude-sonnet-5-5; openai = a dated mid-tier model.

## Non-goals

- No new tiers, no change to any routing default (tiers stay Mistral EU).
- No live refresh of OpenAI availability.
- No residency field (region stays `usage.region` / `regionOfHost`).

## Open point (stated, not blocking)

OpenAI's newest family (`gpt-6-*`, `gpt-5.6-*`) has NO dated snapshot in `/v1/models` (measured 2026-10-11). Those ids are listed with a note saying so, and are not chosen as the default — the default is a dated id, per D-385d97's intent (a default must not move under you).

## Reuse

Discovery check: this IS the shared registry (`@broberg/ai-sdk`) — scout consumes it instead of a local list. Nothing to reuse; building here is the reuse.
