# F022.7 — Gemini-rækkerne i listModels() får grade og default

**Kilde:** jam #3808, videresendt af components #3818 (22/10 2026). Målt af jam på 0.63.0: `listModels({provider:"gemini"})` returnerer `gemini-2.5-flash` og `gemini-2.5-flash-lite` (kind chat, available) uden `grade` og uden `default`. Mistral, OpenAI og Anthropic har begge siden F022.6.

**Konsekvens for jam:** jam vælger en udbyders BYOK-testmodel som dens `grade:"cheap"` (aldrig et hardkodet id). For gemini findes ingen, så jam falder tilbage til billigste `getPrice` — en lokal regel, der kan glide fra SDK'ens.

## Ændring

- `gemini-2.5-flash-lite` → `grade: "cheap"` ($0.10/$0.40 pr. 1M, ai.google.dev 27/8).
- `gemini-2.5-flash` → `grade: "standard"`, `default: true` ($0.30/$2.50).
- Ingen `strong`-række: registret har ingen gemini-pro-række i dag, og at tilføje en er en ny route + pris — uden for dette kort.
- Picker-testen («exactly one default per picker provider») dækker gemini, så en manglende default bliver rød fremover.

**Non-goals:** nye gemini-modeller; ændring af `video`-tieren (gemini-2.5-flash-lite er stadig dens default).

## Reuse

Eksisterende registry i `src/availability/registry.ts` (F022). Ingen ny kapabilitet.

## Rollout

Patch-release (additive felter). Svar jam direkte med versionen.
